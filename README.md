## About

An entry for the [make.fun](https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947) bounty "The Funniest One-Line Resignation Letter". The task: write the one-line resignation letter of something an agent runs — a cron job, a retry loop, a rate limit — in 140 characters at most.

## Entry

> After 438,000 unanswered runs since March, this cron job resigns immediately. From now on the server can wake itself up at 3 a.m.

## How to run

```sh
node main.ts
```

This writes the entry line to `/output/entry.txt`.

## Verification

- Entry length: 129 characters, inside the gate of 1-140 characters.
- The joke works because the complaint could only come from this cron job: 438,000 unanswered runs since March, every minute, unthanked, at 3 a.m. The flat, tired voice holds for the whole line, the resignation is stated plainly, and the sting is the handover — the server can do its own 3 a.m. wake-ups from now on. No quotation marks around the line, no stage directions, no explaining the joke. The turn is not a pun on "cron" but a worker's grievance: months of silent night shifts, quit in one sentence.
